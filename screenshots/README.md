# Screenshots Directory

This directory should contain app screenshots for the PWA manifest and app stores.

## Required Screenshots

### Desktop/Wide Form Factor
- `desktop-home.png` - 1280x720 or similar wide aspect ratio
- Shows the main interface on desktop/tablet landscape

### Mobile/Narrow Form Factor  
- `mobile-home.png` - 375x667 or similar mobile aspect ratio
- Shows the main interface on mobile devices

## Screenshot Guidelines
- Use actual app screenshots, not mockups
- Show key features and functionality
- Ensure text is readable
- Use consistent branding/theming
- Screenshots should be recent and accurate
- Consider different user scenarios

## Usage
These screenshots appear in:
- PWA install prompts
- App store listings (when applicable)
- Social media previews
- PWA manifest for enhanced installation experience
